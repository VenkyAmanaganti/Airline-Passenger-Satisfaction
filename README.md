# Airlines Passenger Satisfaction & Delay Analysis Dashboard
✈️ Airlines Performance Dashboard | Power BI Interactive dashboard analyzing 130K+ airline passenger records. Features KPIs, customer satisfaction analysis, travel type insights, class-wise performance, gender trends, and arrival delay impact. Built using Power BI, DAX, data modeling, and visualization techniques.

## Project Overview

This Power BI project analyzes airline passenger satisfaction, customer behavior, and the impact of flight delays on overall travel experience. The dashboard provides actionable insights into passenger satisfaction across different travel classes, customer types, genders, and travel purposes while highlighting how arrival and departure delays influence customer perceptions.
